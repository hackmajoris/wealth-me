Self-hosted · Go + SQLite

Your money, one month at a time.

Wealth Me is a self-hosted tracker for savings, stocks, crypto, assets and debts. Log each month once, then see your saving rate, returns against the market and net worth over years. Everything stays in a single SQLite file on your machine.

Self-host

Your numbers stay on your machine.

  • One file to back upAll data lives in one SQLite database, in a folder you choose.
  • Optional encryptionSet DB_KEY and the database is encrypted with AES-256 (SQLCipher).
  • Import from CSVBring in your spreadsheet history with the CSV templates for each section.
  • Multiple currenciesChoose a currency for each section. EUR and USD rates are fetched automatically.
# run with Docker
$ git clone https://github.com/hackmajoris/wealth-me
$ cd wealth-me
$ docker compose up -d
✓ open http://localhost:8080

# optional: .env next to docker-compose.yml
DATA_DIR=./data
HOST_PORT=8080
DB_KEY=$(openssl rand -base64 32)

Try it with sample data.

The demo runs entirely in your browser with almost six years of made-up history. Nothing is sent anywhere, and changes reset when you reload.
